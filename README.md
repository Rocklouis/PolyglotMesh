# PolyglotMesh

GraalVM Multi-Language Runtime Sandbox

## Features

- Monaco code editor
- Java, Python and JavaScript tabs
- Python execution
- JavaScript execution
- Run-state handling
- stdout/stderr/error handling
- Console output
- Backend API integration
- Input validation

## Tech Stack

Frontend:
- React
- Vite
- Monaco Editor

Backend:
- Spring Boot
- GraalVM Polyglot
- Java 21

## Running the project

### Backend

mvn spring-boot:run

Backend:
http://localhost:8081

### Frontend

cd frontend
npm install
npm run dev

Frontend:
http://localhost:5173
